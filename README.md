BUFFER 600

해월호텔 야간 관제 기록 — 브라우저에서 바로 하는 단편 관찰형 추리 게임

영업 종료를 일주일 앞둔 해월호텔. 오늘은 당신의 야간 관제 근무 첫날입니다. 카메라는 여덟 대, 모니터는 두 대뿐입니다.

게임 소개
CCTV 화면을 지켜보며 밤사이 일어난 일을 알아내는 관찰형 추리 게임입니다.
모니터는 두 대뿐이라 모든 카메라를 동시에 볼 수 없습니다. 무엇을 볼지 고르는 것부터가 추리입니다.
06:00 전에 누가, 어디서, 언제를 보고서로 제출하세요.
플레이 시간은 약 15~20분입니다. 한 번뿐인 밤이니 처음엔 공략 없이 해 보세요.
실행 방법
index.html, style.css, script.js를 같은 폴더에 둡니다.
index.html을 브라우저로 엽니다. 설치는 필요 없습니다.
소리를 켜고 플레이하는 것을 권장합니다.
조작법
기능 방법
카메라 연결 왼쪽 카메라 목록을 누르면 선택한 모니터(A/B)에 연결
캡처 모니터 아래 📷 버튼 → 타임라인 보드에 저장
다시 보기 녹화 재생은 3회까지 (1회에 10분 분량)
창 이동 창 제목 표시줄을 끌어서 이동
일시정지 오른쪽 위 ❚❚ 버튼 또는 Esc
보고서 작업표시줄 오른쪽 ▧ 보고서 (제출 3회 제한)
지원 환경
PC, 태블릿, 모바일 브라우저 (최신 Chrome, Safari, Edge)
어떤 기기에서도 같은 화면 배치로 보입니다. 휴대폰에서는 가로로 돌려서 플레이하세요.
기술
HTML, CSS, JavaScript만 사용 (외부 라이브러리 없음)
CCTV 장면과 인물은 모두 Canvas로 직접 그림
효과음은 Web Audio API로 합성
파일 구성
index.html 화면 구조
style.css 관제 프로그램 UI와 반응형 스타일
script.js CCTV 렌더링, 사건 진행, 보고서, 엔딩
